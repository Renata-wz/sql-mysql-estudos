# Estudos de SQL e MySQL

Repositório criado para registrar minha evolução nos estudos de SQL e MySQL, com foco em Análise de Dados e Business Intelligence.

## Conteúdos estudados

- Fundamentos de bancos de dados
- Criação e manipulação de tabelas
- INSERT, UPDATE e DELETE
- SELECT
- WHERE
- ORDER BY
- LIKE e BETWEEN
- Funções de agregação
- COUNT, AVG, MIN, MAX e SUM
- GROUP BY
- HAVING
- Modelo Relacional
- Chaves primárias e estrangeiras
- INNER JOIN
- Relacionamentos entre múltiplas tabelas

## Organização do repositório

- `01-fundamentos` — criação de bancos, tabelas e manipulação de dados
- `02-select-filtros` — consultas, filtros e ordenação
- `03-funcoes-agregacao` — funções de agregação
- `04-group-by-having` — agrupamentos e filtros de grupos
- `05-modelo-relacional` — relacionamentos, PK e FK
- `06-joins` — consultas envolvendo múltiplas tabelas
- `07-exercicios` — exercícios de revisão e prática

## Objetivo

Consolidar conhecimentos em SQL por meio de exercícios práticos e construir uma base sólida para projetos futuros de Análise de Dados e BI.
